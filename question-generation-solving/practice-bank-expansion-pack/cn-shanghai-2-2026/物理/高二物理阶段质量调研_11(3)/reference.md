# 物理 / 高二物理阶段质量调研_11(3)

知识点：闭合电路欧姆定律·求内阻
考查要点：该处考查的是闭合电路欧姆定律，需要的技能是识别电动机端电压与定值电阻电压降，并列出电动势分配关系求内阻。
- 由串联电路电流相等，计算定值电阻两端电压 $U_R=IR$。
- 把电动机看作非纯电阻用电器，直接使用题给端电压参与电压分配。
- 根据闭合电路电压关系 $E=U_R+U_M+Ir$ 变形求电池内阻 $r$。
- 区分电动机端电压、电阻分压和电池内电压，避免把所有电压混为一体。

原题（见 question.png）：
某新能源汽车由电池向电动机 $M$ 供电，实验电路中电源电动势 $E=12\ \mathrm{V}$，定值电阻 $R=4\ \Omega$，电动机与定值电阻串联在电路中。
（2）当回路中的电流为 $0.5\ \mathrm{A}$ 时，测得电动机两端电压 $U_M=8\ \mathrm{V}$，求电池内阻。
