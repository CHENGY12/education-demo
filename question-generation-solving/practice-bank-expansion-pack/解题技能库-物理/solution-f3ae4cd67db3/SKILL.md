# 感应电荷量的磁通端点与总变差法

## 适用场景

- 变化磁场中的回路电荷量
- 转动线圈给定角度的电荷量
- 完整周期净电荷
- 正反方向电荷绝对累计

## 解题步骤

1. 明确匝数、单匝磁通和磁通链，避免重复计入匝数。
2. 确认全过程总电阻可视为恒定。
3. 求代数净电荷时使用起止磁通链的代数差除以总电阻。
4. 求绝对累计电荷时按磁通变化率变号或磁通达到极值的时刻分段，对每段变化取绝对值后相加。
5. 转动线圈先用法线与磁场夹角表达磁通，再代入端点。

## 必做复核

- 结果是否与过程快慢无关
- 总电阻是否包含全部串联电阻
- 电流反向依据是否为磁通变化率变号
- 完整周期净量和累计量是否区分

## 常见误区

- 不能用峰值电动势乘总时间替代积分
- 磁通穿过零不必然意味着电流反向
- 磁通为零与感应电动势为零不是同一条件
