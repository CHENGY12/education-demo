# 力—时间图像的带符号冲量结算

## 适用场景

- 由分段力图求末速度
- 反求峰值力或作用时间
- 图示力与其他恒力并存
- 作用结束后继续追踪运动

## 解题步骤

1. 规定正方向，把初末速度和各段力写成带符号量。
2. 按几何面积或分段积分计算图线相对时间轴的有向面积。
3. 判断图像表示合力还是某一分力，将未包含的其他外力冲量另行加入。
4. 用末动量等于初动量加总冲量求状态，并在阶段边界更新初值。
5. 峰值受限的最短时间题先判断最优过程是否取到允许峰值边界，再由所需面积反求。

## 必做复核

- 图像表示合力还是单个力
- 轴下方面积是否取负
- 是否重复或遗漏重力等其他冲量
- 分段末态是否传给下一段
- 冲量方向是否与动量变化一致

## 常见误区

- 峰值力不是平均力
- 不能只算面积大小而丢失方向
- 接触力结束后不能继续作用
