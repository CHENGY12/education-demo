# 热运动、扩散与布朗记录的层级判读

## 适用场景

- 辨析扩散与布朗运动
- 解释均匀混合后的动态平衡
- 比较不同温度或粒径下的布朗运动
- 判读离散位置记录图

## 解题步骤

1. 先确定观察对象是分子、悬浮微粒还是宏观浓度分布。
2. 将扩散解释为分子热运动造成的统计混合，将布朗运动解释为分子碰撞瞬时不平衡造成的微粒运动。
3. 把宏观均匀表述为相反方向统计通量相抵，而非微观运动停止。
4. 比较记录图前统一实际长度标尺和取样间隔，并把连线仅视为离散采样表示。
5. 比较温度或粒径影响时控制介质、尺度、对流和机械振动等混杂因素。

## 必做复核

- 扩散和布朗运动的运动主体是否混淆
- 是否把宏观稳定误写成微观静止
- 是否把采样折线当成真实轨迹
- 比较图像时长度尺度和取样时间是否一致
- 是否排除了搅拌、对流和显示放大

## 常见误区

- 显微镜中可见的通常不是液体分子
- 净位移方向不能证明全时段存在同向合力
- 大颗粒并不因碰撞次数多就必然有更明显的布朗运动
