# 双物体弹簧系统的质心—相对运动分解

## 适用场景

- 两物体由轻弹簧连接
- 求最大弹性势能
- 求速度极值
- 求再次原长时速度

## 解题步骤

1. 从外部约束解除后重新选系统，记录总动量、机械能和初始形变量。
2. 由总动量求恒定质心速度，将质心平动能作为不可转化的能量底座。
3. 最大形变时相对速度为零，两物体共速，弹性势能最大。
4. 用总机械能减质心平动能求最大弹性势能。
5. 弹簧回到相同形变量时联立总动量和机械能，并按运动连续性选择相对速度分支。

## 必做复核

- 动量守恒起点是否在外部约束消失后
- 最大形变条件是否为共速而非都静止
- 最大势能是否扣除了质心动能
- 再次原长结果是否同时满足动量和能量

## 常见误区

- 仍受墙或挡板时不能擅用系统动量守恒
- 总机械能不能全部转化为弹性势能
- 仅用能量方程无法唯一确定速度分支
