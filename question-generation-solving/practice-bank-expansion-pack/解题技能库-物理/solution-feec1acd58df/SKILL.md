# 弹簧振动的平衡位置平移与恒力突变

## 适用场景

- 竖直或斜面弹簧振动
- 突然加挂、卸载或剪断
- 恒定电场力撤去或反向
- 由端点状态求支持力或参数

## 解题步骤

1. 统一规定弹簧形变量符号，分别求突变前后静力平衡形变量。
2. 以突变后平衡位置为新原点，把实际形变量减去新平衡形变量。
3. 检查突变是否可忽略冲量；若可，则位置连续且速度不突变。
4. 突变前静止时，相对新平衡点的初位移绝对值就是振幅；有初速度时用相空间或能量合成。
5. 使用突变后的实际振动质量求角频率，并在端点按加速度指向平衡位置列受力式。

## 必做复核

- 平衡条件是否使用实际随动质量
- 振幅是否为到新平衡点的距离
- 恒力反向时改变量是否包含双向差值
- 角频率是否使用突变后质量
- 端点加速度方向是否正确

## 常见误区

- 实际弹簧形变量不等于简谐位移
- 重力或恒力通常移动平衡点而非直接改变角频率形式
- 有初速度或冲量时不能直接用平衡点差作振幅
