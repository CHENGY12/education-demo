# 近频波叠加的相对相位时钟

## 适用场景

- 两列近频波叠加
- 求拍频或拍周期
- 求首次相消时间
- 统计区间内指定合成状态

## 解题步骤

1. 计算频差并写出相对相位随时间的线性关系。
2. 把初始同相、反相或一般初相写入相位初值。
3. 将目标现象翻译成相对相位条件。
4. 解出满足条件的通项时刻，并按时间区间筛选整数序号。
5. 区分包络完整重复周期与从相长到首次相消的时间。

## 必做复核

- 一个拍周期后相对相位是否增加整周
- 首次由同相到完全相消是否对应半周相对相位
- 区间端点是否按题意处理
- 拍频是否显著小于载波频率

## 常见误区

- 首次相消时间不是完整拍周期
- 不能忽略初始相位
- 计数时不能遗漏端点或周期内多解
