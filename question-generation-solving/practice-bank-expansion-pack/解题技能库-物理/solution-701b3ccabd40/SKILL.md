# 理想变压器网络的同侧负载折算

## 适用场景

- 变压器与串联电阻组合
- 含线路电阻的输电负载
- 副边端口伏安关系
- 负载或匝数比的最大功率优化

## 解题步骤

1. 统一定义匝数比方向并选定等效侧。
2. 按匝数比平方将另一侧电阻折算到等效侧。
3. 在等效侧重画普通电阻网络，求电流、压降和功率。
4. 需要跨回另一侧时再使用电压正比于匝数、电流反比于匝数的关系。
5. 负载可变时建立端口等效内阻；求最大功率先找无约束匹配点，再检查可行范围。

## 必做复核

- 电阻折算方向和平方因子是否正确
- 电压、电流是否属于同一侧
- 是否扣除了线路或串联电阻压降
- 折算前后负载功率是否一致
- 最优点是否满足变量范围

## 常见误区

- 电阻不能按匝数比一次方折算
- 副边电阻不能直接与原边电阻相加
- 最大功率、最高效率和最小线损不是同一条件
