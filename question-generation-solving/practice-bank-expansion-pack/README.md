# 举一反三扩题说明

为每个知识点扩充举一反三题，按低、中、高三档，**每档不少于 5 题**（每节点不少于 15 题）。

本说明的格式与规范据前几批交付中发现的问题整理，要求较早期版本更严。**多数问题可由 `validate.py` 静态查出，但答案对错、双答案、干扰项歧义只能靠人工核对**——见第七节。交付前须 `validate.py` 全绿，且完成第七节的人工核对。

## 目录结构

```
practice-bank-expansion-pack-.../
    README.md               本说明
    validate.py             自检脚本
    INVENTORY.md            节点清单
    cn-shanghai-2-2026/     上海物理（简体）
        物理/
            高二物理阶段质量调研_1/
                question.jpg    原题图
                reference.md    知识点、考查要点、原题文字
                questions.jsonl 题库文件；已含种子题，在此判定与补充
            ...
    hk-hongkong-1-2026/     香港数学（繁体）
        数学/
            中五數學卷一_1/
            ...
```

香港数学为**繁体中文**：题干、选项、解析一律用繁体（公式 LaTeX 写法与简体一致）。

## 一、你要做什么

每个知识点的 `questions.jsonl` 里已放入一道**种子题**（由原题生成）作参考，其 `difficulty` 与 `pool` **是空的**。

1. **判定种子题的难度**：判断它属于 `low` / `mid` / `high`，填入 `difficulty`（种子题原有标注不可靠，一律重判）。
2. **判定种子题的池**：填 `pool`——`display`（展示给学生练习）/ `exam`（保留出卷、学生不可见）。
3. **补足每档**：`low` / `mid` / `high` 各补到 **≥5 题**（含种子题）。
4. **保证池配比**：每档 `display` **≥3**、`exam` **≥2**。
5. **均衡答案**：见第五节。
6. **自检交回**：`python3 validate.py` 全绿，并完成第七节人工核对后交回 `questions.jsonl`。

> 种子题若为多选（`answer` 含两个字母）或与知识点不符，按单选题重写或另出，不要照用。

## 二、题目字段

每行一道题（JSONL）。

| 字段 | 取值 |
| --- | --- |
| `id` | `pb_<学科>_<nodeId>_<难度>_<三位序号>`；新增题序号顺延 |
| `nodeId` / `subject` | 照抄种子题 |
| `difficulty` | `low` / `mid` / `high` |
| `pool` | `display`（展示练习） / `exam`（保留出卷，学生不可见） |
| `prompt` | 题干 |
| `options` | 恰 4 项，`id` 依次 A / B / C / D |
| `answer` | A / B / C / D，须与正确选项一致（单选，不得双答案） |
| `explanation` | 解析 |
| `skillTarget` / `hint` | 可选 |

## 三、公式格式（`validate.py` 逐条静态检查）

平台三端渲染器只认 `$...$`（行内）与 `$$...$$`（独立公式）。以下每条都踩过坑，务必遵守。

| # | 要求 | 反例 → 正例 |
| --- | --- | --- |
| 3.1 | **反斜杠须转义**：用 `json.dump` 写文件，写后重读确认无控制字符 | 换页符+`rac` → `\\frac`（存储为 `\\frac`） |
| 3.2 | **定界符只用 `$` `$$`**，不用 `\( \)` `\[ \]`；每个 `$` 成对闭合 | `\(v=at\)` → `$v=at$` |
| 3.3 | **公式外不得有裸公式**：变量、表达式、方程、上下标、带单位数值一律进 `$…$` | `mgh=\tfrac12MV^2` → `$mgh=\tfrac12MV^2$`；`v^2` → `$v^2$`；`10^-8` → `$10^{-8}$` |
| 3.4 | **不用 Unicode 数学符号**，一律 LaTeX 命令 | `√2` `≥` `×` `∈` `∞` → `$\sqrt2$` `\ge` `\times` `\in` `\infty` |
| 3.5 | **不用 ASCII 伪数学** | `sqrt(2)/2` `frac` `cosh` → `$\sqrt2/2$` 等 |
| 3.6 | **化学式、元素、离子、状态符 `(s)(g)(l)(aq)` 用 `\mathrm{}` 正体**；物理量符号保持斜体（不加 `\mathrm`） | `$CaCl_2$` → `$\mathrm{CaCl_2}$`；`$r(Si)$` → `$r(\mathrm{Si})$`；浓度 `$c$`、体积 `$V$` 保持斜体 |
| 3.7 | **不用 `\ce{}`**（平台无 mhchem），化学方程用 `\mathrm` | `$\ce{2H2+O2->2H2O}$` → `$\mathrm{2H_2+O_2 \rightarrow 2H_2O}$` |
| 3.8 | **下标花括号内只放数字**；键线短横写在花括号外 | `CH_{3-}CH_{2-}` → `CH_{3}-CH_{2}-` |
| 3.9 | **指数分组不错位**：每个能级指数单独花括号闭合 | `$3d^{64}s^{2}$` → `$3d^{6}4s^{2}$`；`$4s^{24}p^5$` → `$4s^{2}4p^5$` |
| 3.10 | **每个 `$…$` 内左右花括号数量相等** | `$\sqrt{3l^2+4b^2$`（缺 `}`）→ `$\sqrt{3l^2+4b^2}$` |
| 3.11 | **`\text{}` 内不含 `_` `^`**：化学式部分改 `\mathrm`，中文与标点留 `\text` | `\text{NaOH_2}` → `\mathrm{NaOH}_2` |
| 3.12 | **公式内中文用 `\text{}` 包裹**；作连接词的中文（「与」「和」）留在公式外 | `$a_3与a_7$` → `$a_3$ 与 $a_7$`；`$P(患病\mid服药)$` → `$P(\text{患病}\mid\text{服药})$` |
| 3.13 | **公式内 `%` 写作 `\%`** | `$50%$` → `$50\%$` |
| 3.14 | **写文件前关终端着色**（`NO_COLOR=1`），文件不含 ANSI 转义码 | `$<ESC>[1m x<ESC>[0m$` → `$x$` |

## 四、题目结构

| # | 要求 |
| --- | --- |
| 4.1 | **选项内容只写进 `options[].text`**，题干不得重复列出 A/B/C/D；`options[].text` 不得只是字母 |
| 4.2 | 平台不渲染 markdown 表格，选项不得以表格承载 |
| 4.3 | **一题只有一个正确选项**；`answer` 为单个字母 |
| 4.4 | **四个干扰项两两不指向同一答案/同一化合物**；命名类题四项须在主链、位次或取代基上有实质差异 |
| 4.5 | **干扰项的正误在教材口径下唯一确定**，不留「按另一版本也成立」的歧义 |
| 4.6 | **`explanation` 不含出题流程/生成失败用语**：「独立解」「独立核验」「更正如下」「规范写为」「实际应为」等，及空公式（`$$x=$$`） |

## 五、答案分布

| # | 要求 |
| --- | --- |
| 5.1 | **整批**正确答案在 A/B/C/D 间大致均衡，各项占比宜 20%–30% |
| 5.2 | **每个知识点内部**正确答案也要分散，**单字母占比 ≤40%**（`validate.py` 按节点查）；不得出现「一个节点里连着十几道都选 A」 |
| 5.3 | **解析结论统一写「故选X。」放末尾**，X 与 `answer` 一致。不要用「对应X」「即X」指代选项（几何题会与点 A、角 B 混淆） |
| 5.4 | 调整选项顺序时，**必须同步改三处**：`answer`、解析结论字母、解析中一切按字母指代选项的表述 |

## 六、句末标点（中文全角）

| 对象 | 规则 |
| --- | --- |
| 选择题题干（≥2 选项） | 引出型（`…的是`/`分别为`/`包括`）→ 冒号 `：`；疑问型（`…是什么`/`多少`/`吗`）→ 问号 `？`；**作答括号 `（ ）` 结尾 → 保留括号、其后不加任何标点** |
| 解答题题干 | 陈述/指令句 → 句号 `。`；以冒号引出下文（`求：`）→ 保留冒号 |
| 选项 | 完整陈述句 → 句号 `。`；短语/纯公式/纯数值/答案片段 → 不加；**同一题 A–D 风格一致** |
| 解析 | 完整中文陈述 → 句号 `。`；末尾为块级公式 `$$…$$` → 不加 |
| 全局 | 只补全角标点；已有终止标点不叠加（不得出现 `：。` `。。` `（ ）。`）；公式内标点不动 |

## 七、答案核对（人工，`validate.py` 查不了）

**这一节是格式校验查不出、也最容易出问题的部分。** 已有批次里，生成时的自检记录（`answer_review.jsonl`）全部 `pass`、三个求解器全一致，仍漏掉了真实答案错误和题目缺陷。

- **交付前做一次「剥离答案独立重解」**：把 `answer` 遮住，自己（或另一模型）把题重解一遍，再与库内 `answer` 比对。这是唯一能查出下列问题的手段：答案本身错、题干条件不全、题干数字错、表述歧义、中英文混入。
- 只依赖生成时的自检记录不够——**记录齐全 ≠ 答案已把关**。

## 八、交付与自检

1. **打包不含 macOS 垃圾**：`._*`、`.DS_Store`、`__MACOSX/`；目录名不带 ` copy` 后缀。
   打包：`COPYFILE_DISABLE=1 tar czf <包>.tar.gz <目录>/`；或清理：`find . -name '._*' -delete; find . -name .DS_Store -delete`。
2. **附 `manifest.json`**：每个 `questions.jsonl` 的相对路径、题数、sha256、字节数，以及全包节点数、题目总数、难度/池分布、答案分布。
3. **跑自检**：
   ```
   python3 validate.py                         检查全部
   python3 validate.py hk-hongkong-1-2026/数学   检查指定范围
   ```
   脚本逐节点报是否达标及缺项（结构、难度/池、配比、公式、标点、节点答案偏倚、解析结论字母）。**全绿方可交回。**
4. **`validate.py` 全绿 ≠ 完工**：静态检查过不代表答案对。必须另做第七节的人工重解核对。
