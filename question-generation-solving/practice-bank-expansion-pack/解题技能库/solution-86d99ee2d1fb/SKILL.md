# 串联电路中电动机效率与机械功率的求解

## 适用场景

- 电动机与若干电阻串联且处于稳定工作状态
- 已知电源电动势、电阻参数及电动机效率
- 忽略电动机线圈发热之外的其他损耗

## 解题步骤

1. 设串联电流、电动机端电压和线圈电阻。
2. 写出电动机输入功率与线圈发热功率。
3. 利用效率定义建立端电压与电流的关系。
4. 把电源内阻和其他串联电阻合并，列闭合电路电压关系。
5. 联立求出电流和电动机端电压。
6. 由效率乘输入功率或由输入功率减焦耳热求机械输出功率。

## 必做复核

- 分别用效率关系和能量守恒计算机械功率，检查结果是否一致。
- 检查电源总功率是否等于各电阻发热功率与机械输出功率之和。
- 检查电动机端电压、电流及各项功率是否为合理的正值。
- 检查所有电压、功率关系的单位量纲是否一致。

## 常见误区

- 把电动机当作仅含线圈电阻的纯电阻元件。
- 遗漏电源内阻或外接串联电阻上的电压降。
- 将效率误写成机械功率与线圈发热功率之比。
- 把电动机输入电功率直接当作机械输出功率。
