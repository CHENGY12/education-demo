# 平行长直载流导线作用力的比例与矢量叠加

## 适用场景

- 多根可视为无限长且彼此平行的直导线
- 要求比较参数变化前后的单位长度作用力
- 要求求某根导线所受合力、方向或平衡条件
- 导线位置构成直线、三角形、正方形等平面几何图形

## 解题步骤

1. 明确目标导线，并列出其余每根导线对它产生的作用力。
2. 依据电流同向相吸、反向相斥确定每个分力沿两导线连线的方向。
3. 用 $f=\frac{\mu_0 I_1 I_2}{2\pi r}$ 计算各分力大小，或选取公共力尺度进行比例计算。
4. 建立坐标系，将不共线的分力分解为正交分量。
5. 分别求各方向分量的代数和，再计算合力大小与方向。
6. 若合力为零，分别令各正交分量为零并求未知参数。

## 必做复核

- 逐项复核吸引力是否指向另一根导线，排斥力是否背离另一根导线。
- 检查作用力是否随任一电流增大而增大、随间距增大而减小。
- 用对称性或几何关系复核合力方向。
- 将所得分量重新合成，核对大小、方向和平衡条件。
- 检查结果具有单位长度力的量纲，纯倍率或电流倍数应无量纲。

## 常见误区

- 把同向电流误判为排斥或把反向电流误判为吸引。
- 忽略不同导线间距，直接按电流大小比较作用力。
- 把斜向作用力的大小直接当作某一坐标分量。
- 只相加作用力大小而不考虑方向。
- 混淆导线所受总力与单位长度所受力。
