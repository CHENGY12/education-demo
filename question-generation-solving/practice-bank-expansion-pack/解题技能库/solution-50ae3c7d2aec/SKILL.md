# 电场加速后进入匀强磁场的分阶段建模

## 适用场景

- 粒子从静止或已知初速度出发，经已知电势差加速
- 粒子垂直进入匀强磁场且可忽略重力等其他力
- 需要求进入磁场时的速率、动量或圆周轨道参数

## 解题步骤

1. 划分电场加速阶段和磁场运动阶段，明确各阶段的已知量与待求量。
2. 在加速阶段应用动能定理，求粒子进入磁场时的动能、速率或动量。
3. 在磁场阶段确认速度与磁场垂直，并令洛伦兹力提供向心力。
4. 联立两阶段关系，消去中间变量并化简目标量。
5. 根据题目给出的电荷量含义处理符号；求大小时使用电荷量的绝对值。

## 必做复核

- 检查磁场力是否与速度垂直，以确认其只改变速度方向。
- 检查轨道半径随磁场强度、电势差、质量和电荷量变化的趋势是否合理。
- 用基本关系核对结果的长度、速度或动量量纲。
- 逐项代入或比较参数依赖，确认选择题答案唯一。

## 常见误区

- 把电势差直接当作粒子的动能，遗漏电荷量因子。
- 在洛伦兹力公式或向心力公式中漏写速度因子。
- 未确认速度与磁场的夹角便直接使用垂直入射关系。
- 混淆带符号的电荷与电荷量大小，导致半径出现不合理的负值。
- 在消去速率时错误处理平方根或质量、电荷量的位置。
