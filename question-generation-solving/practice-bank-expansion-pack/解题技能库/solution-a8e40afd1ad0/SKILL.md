# 匀强磁场条带中出射偏移量的单调性比较

## 适用场景

- 粒子在磁场区域内仅受洛伦兹力并做匀速圆周运动
- 入射速度垂直于磁场且入射方向垂直于条带边界
- 粒子能够到达磁场条带的对侧边界
- 需要比较参数变化前后的出射偏移量

## 解题步骤

1. 由洛伦兹力提供向心力，写出轨道半径与粒子参数、速率和磁感应强度的关系。
2. 根据电荷符号、入射方向和磁场方向判断轨迹弯曲方向。
3. 设条带宽度为 $w$、轨道半径为 $r$，利用圆周几何写出偏移量 $h=r-\sqrt{r^{2}-w^{2}}$。
4. 将偏移量有理化为 $h=\frac{w^{2}}{r+\sqrt{r^{2}-w^{2}}}$，据此判断其随半径的单调性。
5. 把外部参数的变化转化为轨道半径的变化，再比较出射偏移量。

## 必做复核

- 检查到达对侧边界所需的半径条件是否满足。
- 核对洛伦兹力方向与圆心位置是否一致。
- 用半径等于条带宽度的边界情形检查几何表达式。
- 考察半径很大时偏移量趋近于零的趋势是否合理。
- 检查所有半径、宽度和偏移量均具有长度量纲。

## 常见误区

- 仅凭轨道半径比例直接假定偏移量也成相同比例。
- 忽略粒子可能无法到达对侧边界的几何条件。
- 混淆竖直坐标与竖直偏移量的大小。
- 判断偏转方向时忽略电荷正负。
- 选取了圆与对侧边界的后一个交点，而非粒子运动中首先到达的交点。
