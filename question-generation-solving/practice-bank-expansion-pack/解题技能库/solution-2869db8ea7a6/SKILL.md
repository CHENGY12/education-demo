# 电路切换后电磁力与瞬时加速度的联立分析

## 适用场景

- 电源具有不可忽略的内阻，且开关动作会改变外电路结构
- 载流导体在磁场中受到安培力，且切换瞬间位置与速度可视为不变
- 切换前存在静力平衡或已知受力状态，可用于标定初始安培力

## 解题步骤

1. 根据切换前的端电压、负载和电流关系求电源内阻或其他未知电路参数。
2. 按切换后的实际连接方式计算外电路等效电阻。
3. 用闭合电路欧姆定律求总电流和路端电压，再由支路关系求载流导体中的电流。
4. 确认切换瞬间磁感应强度、导体有效长度和方向是否改变。
5. 利用安培力与支路电流的比例关系求切换后的安培力。
6. 结合重力及其他力，用牛顿第二定律判断加速度的大小和方向。

## 必做复核

- 用各支路电流之和核对电源总电流。
- 检查内阻电压降与路端电压之和是否等于电动势。
- 检查负载变化引起的路端电压和支路电流变化是否符合物理趋势。
- 检查合力方向与所得加速度方向是否一致。
- 检查电流、电压、电阻、力和加速度的单位量纲。

## 常见误区

- 把电源电动势误当作切换前后恒定的路端电压。
- 只计算并联等效电阻而未继续求载流导体所在支路的电流。
- 忽略电源内阻导致负载变化时路端电压也会变化。
- 未确认电流方向或磁场条件便直接确定安培力方向。
- 把总电流的变化比例误当作载流导体支路电流的变化比例。
