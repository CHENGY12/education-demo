# 速度选择器与磁场偏转的分阶段建模

## 适用场景

- 粒子在速度选择器中沿直线无偏转运动
- 电场力与磁场力方向相反且速度垂直于磁场
- 粒子随后垂直进入匀强磁场做匀速圆周运动
- 可忽略重力及其他影响运动的力

## 解题步骤

1. 在速度选择阶段，根据无偏转条件令电场力与洛伦兹力大小相等。
2. 由力的平衡关系求出被筛选粒子的速率。
3. 在磁场偏转阶段，确认粒子速度与磁场垂直。
4. 令洛伦兹力提供向心力，建立轨道半径与速率、比荷及磁感应强度的关系。
5. 联立两个阶段的关系，消去速率并求目标物理量。

## 必做复核

- 检查速度选择器中的两种力是否方向相反。
- 检查进入偏转磁场时速度是否与磁场垂直。
- 核对结果的单位量纲是否与目标物理量一致。
- 检查轨道半径随速率和磁感应强度变化的趋势是否合理。
- 对选择题逐项比较参数的位置与幂次，确认答案唯一。

## 常见误区

- 把速度选择器中的磁感应强度与偏转磁场的磁感应强度混为一谈。
- 忽略无偏转条件要求电场力与磁场力方向相反。
- 在洛伦兹力或向心力表达式中遗漏速率因子。
- 未确认垂直入射便直接使用圆周运动半径关系。
- 混淆电荷的代数值与电荷量大小。
