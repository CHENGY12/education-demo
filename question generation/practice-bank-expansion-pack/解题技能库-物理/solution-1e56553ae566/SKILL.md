# 动生电动势导体的含源支路等效

## 适用场景

- 导体棒切割磁感线
- 部分进入磁场的线框
- 测量含源段端电压
- 计算匀速维持功率

## 解题步骤

1. 识别真正产生动生电动势的导体段，确定电动势大小和极性。
2. 确定该段内阻及其余外电路等效电阻。
3. 把含源段视为电动势与内阻串联，求闭合回路电流。
4. 含源段端电压按电动势与内部压降合成，无源段按电阻压降计算。
5. 匀速且无储能变化时，用机械功率等于全回路焦耳热或电动势乘电流复核。

## 必做复核

- 电压表跨接部分是否包含电动势源
- 端电压是否被误写成单纯电阻压降
- 局部热功率和总功率是否区分
- 机械功率是否等于全部电阻热功率

## 常见误区

- 含源导体端电压一般不等于自身电阻压降
- 均匀导线电阻应按长度分配
- 单个电阻热功率不能使用全回路总电阻
