# 相干波的总相位差与有符号振幅合成

## 适用场景

- 源初相和路程差同时存在
- 由单列强度求合强
- 判断干涉点同相或反相
- 求两点最大高度差

## 解题步骤

1. 选定相位差次序，将源初相差和路程或时延造成的传播相位差合成。
2. 把路程差换成空间相位差，必要时对整周取模。
3. 由强度开平方得到相对振幅，再用相量合成式求合振幅或合强。
4. 需要比较多个点时，以同一简谐因子表示各点，并给合振幅附上相位符号。
5. 更新位置或源相位后重新计算总相位差，不沿用旧的加强减弱结论。

## 必做复核

- 同相和反相极限是否分别给出振幅和与振幅差
- 合强是否位于允许最大最小值之间
- 是否误把声强直接相加
- 两点最大高度差是否考虑有符号相位

## 常见误区

- 振幅比不是声强比
- 源相位超前与传播滞后不能不分符号地相加
- 某时刻位移为零不等于该点始终静止
