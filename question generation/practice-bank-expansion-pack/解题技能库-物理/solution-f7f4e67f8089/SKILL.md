# 几何作图实验的方向误差控制

## 适用场景

- 用若干标记点拟合光线、轨迹或其他直线方向
- 通过几何偏移或偏转现象间接测量物理量
- 需要比较实验器材尺寸、测量位置或定位间距对误差的影响

## 解题步骤

1. 识别直接测量量及其绝对定位误差来源，如标记宽度、视差、边界不规则或作图偏差。
2. 判断目标量是否由两点连线或直线拟合得到；若是，应在可操作范围内增大定位点之间的有效基线。
3. 增大与待测效应相关的可观测位移或角度差，使物理效应明显高于定位误差。
4. 选择规则、清晰且远离边缘缺陷的测量区域，避免局部不规则引入系统偏差。
5. 同时检查参数是否过大而导致越界、重合困难或模型条件失效，在灵敏度与可操作性之间取平衡。

## 必做复核

- 比较定位误差与有效基线之比；该比值越小，方向误差通常越小。
- 确认调整后待观察的位移或偏转更加明显，而不是仅增大器材尺寸却未提高可辨识度。
- 确认测量点没有落在边缘、缺陷或刻线模糊区域。
- 确认所选参数仍满足实验模型的适用条件，且全部关键点位于可测范围内。

## 常见误区

- 误以为所有角度越小越能减小误差；角度过小时，偏转效应可能难以分辨。
- 把定位点安排得过近，导致相同的点位误差被放大为更大的方向误差。
- 在器材边缘测量，忽略边缘不规则和边界识别困难造成的系统误差。
- 只追求增大某个参数，不检查是否导致光路越界、作图困难或近似条件失效。
