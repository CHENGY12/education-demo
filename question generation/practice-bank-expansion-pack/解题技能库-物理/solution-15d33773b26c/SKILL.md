# 可动载体上的相对滑动能量核算

## 适用场景

- 物块在可动木板上滑至共速
- 小车内物体摩擦停止
- 分段粗糙面相对滑动
- 具有共同初速度的相对运动

## 解题步骤

1. 把物块和载体作为系统，由水平动量守恒求末态共同速度。
2. 比较初末系统总动能及其他势能，得到摩擦耗散总量。
3. 把各阶段生热写成摩擦力乘该阶段相对滑动距离。
4. 初末共同平动相同时可先消去共同平动能。
5. 分段粗糙时按顺序扣除各段耗散，再求目标区段相对距离。

## 必做复核

- 摩擦生热是否使用相对路程
- 末态共同速度是否由总动量确定
- 分段耗散之和是否等于机械能减少
- 整体平移改变时相对结论是否保持

## 常见误区

- 摩擦对单个物体的功不等于系统生热
- 不能用物块对地路程代替相对路程
- 多段粗糙面不能用同一摩擦系数一次结算
