# 含系统偏差关系的线性化与斜截距解码

## 适用场景

- 平方、倒数或相除后的实验作图
- 固定零点偏差或比例误差
- 理想气体状态方程线性化
- 由图线比较样品量或物理参数

## 解题步骤

1. 写出完整真实物理关系及测量值与真值的变换关系。
2. 消去真值，严格改写成题目实际横纵轴变量的一次式。
3. 与标准直线式逐项对应斜率、截距和单位。
4. 识别加性误差通常进入截距，比例误差通常缩放斜率；变量经过平方时倍率也要平方。
5. 用差分求斜率；条件或样品量改变后为新阶段建立新的常量关系。

## 必做复核

- 横纵坐标是否与推导式一致
- 斜率单位是否符合物理含义
- 非零截距时是否避免单点纵横比
- 加性和乘性误差是否正确归位
- 比较斜率前控制条件是否一致

## 常见误区

- 不能凭熟悉公式直接读取斜率
- 看到倒数坐标不应自动判为双曲线
- 零点偏差与比例误差的图像效应不同
